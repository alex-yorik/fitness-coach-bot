# TECH_DEBT.md

Технические долги проекта `fitness-coach-bot`.

Формат: **описание проблемы** → **цель/способ закрытия** (для открытых) или
**дата закрытия + способ** (для закрытых). Закрытые пункты не удаляются — они
доказывают, что долг реально закрыт.

## Открытые

### 2026-10-29 — Отдельный демо-экземпляр не реализован

Отдельный демо-экземпляр только для чтения (вымышленные данные, ограниченный контейнер) не реализован; требуется для безопасного живого показа.

### 2026-08-14 — Веб-админка отдаётся по HTTP без TLS

`SESSION_COOKIE_SECURE` в коде по умолчанию `True` (fail-closed), но в рабочем
`.env` временно `False`, т.к. админка доступна по `http://IP:5004`. Браузер не
хранит Secure-cookie по HTTP, поэтому без TLS флаг ломает логин.

Решение владельца 2026-10-29: админка не публикуется; живой показ выполняется через скриншоты и запись экрана. TLS в репозиторий не добавляется.

- Решение владельца 2026-10-27: TLS для демо-экземпляра не добавляется; админка не используется с реальными данными.

### 2026-08-14 — Прямой SQL без ORM

Вся работа с БД — сырые `sqlite3`-запросы (`app/database.py`, `admin/web.py`,
`app/handlers/trial.py`). Схема одна таблица, поэтому ORM избыточен, но при росте
схемы (миграции, связи) запросы станут рассадником ошибок и дублирования.

Закрыть: если схема перестанет умещаться в одну таблицу — внедрить миграции
(например, `alembic` + параметризованные запросы остаются обязательными).
Целевой срок: **к Q3 2026**.

### 2026-08-14 — Rate-limiter админки использует in-memory хранилище

`flask-limiter` сконфигурирован без storage backend — лимиты хранятся в памяти
процесса (Flask по умолчанию, предупреждение в логах pytest). При запуске
нескольких реплик админки лимиты будут считаться независимо.

Закрыть: при переходе на >1 реплику админки подключить Redis backend
(`RATELIMIT_STORAGE_URI`). Для single-instance прода допустимо. Целевой срок:
**по потребности** (документировано в `SECURITY.md`).

Закрыт: **2026-08-14** — рефакторинг на одноответственные функции,
повторный прогон `python scripts/check_modularity.py .` проходит:
